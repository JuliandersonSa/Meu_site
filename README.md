# Meu Site

Este é um site simples desenvolvido para apresentar tutoriais passo a passo com imagens explicativas.

O projeto é baseado em HTML, e tem como objetivo auxiliar no aprendizado de tarefas como a instalação e configuração do sistema Armbian para TV Boxes.

## 🎯 Objetivo

- Compartilhar conhecimento com linguagem simples
- Explicar procedimentos técnicos com imagens e organização clara
- Servir de apoio para usuários iniciantes

## 📂 Estrutura

- `index.html`: página inicial com links para tutoriais
- Arquivos `.png`: capturas de tela dos passos realizados
- Textos e imagens explicando processos como:
  - Uso do balenaEtcher
  - Criação e cópia de arquivos em cartões SD
  - Instalação do Armbian
